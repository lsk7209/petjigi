# Goal — PetJigi core guides

Final Deliverable: Six existing public representative articles with source-backed decisions, practical tables/checklists, related links and rollback-ready release documentation.
User Value: Owners can prepare for adoption, read food labels, contact a vet, compare insurance, improve a cat's home and arrange a funeral.
Required Features: Preserve publication/reviewer metadata; verify sources; merge only same-intent pages; verify actual seed bodies in isolated desktop/mobile runtime.
Non-Goals: Production DB writes, push, deployment, AdSense submission, expert review claims, bulk noindex/deletion, new dependencies.
Done Conditions: Target content and reciprocal links reviewed; gate/tests/typecheck/lint/build/E2E pass; independent review resolved; release evidence records external gaps.
User-Visible Result: Local content changes ready for separately authorized production reconciliation.
