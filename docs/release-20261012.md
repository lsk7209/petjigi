## 릴리스 보호

이전 두 단계의 검증된 콘텐츠·도구·탐색·지역 안내를 함께 반영한다. 변경 명세는 `release-content-manifest-20261012.json`: 27개 시드 행, 공개 운영 대상 26개 slug이다. 은퇴한 guide 청구 원본과 실제 공개 blog 청구 행을 구분한다. 원본 id/type/status/publishedAt/reviewer 메타데이터는 보존한다.

마이크로칩 글의 운영 검색 제목은 현재 HEAD와 달랐다. 이번 변경 목록은 본문만 포함하므로 운영 검색 제목을 보존한다. 보험 2편의 출처 차이는 과거 JSON.stringify 시드의 중첩 문자열 인코딩을 풀어서 원본과 대조했다. 검증하지 않은 운영 차이를 일괄 덮어쓰지 않는다.

업데이트 스크립트는 제목·검색 제목·부제·본문·설명·출처·고지·수정일을 다루며 `--manifest`로 실제 변경 필드만 제한한다. `--expected-snapshot`은 점검한 행 ID·slug·상태·필드가 현재 조회 값과 같아야 허용한다. SQL CAS는 조회 후 변경된 본문 및 쓰려는 필드의 덮어쓰기를 막는다. 기존 백업은 보존하고 새 8필드 백업은 `.backup-prod/release-20261012/fields/`에 저장한다. 불완전하거나 현재 값과 다른 기존 백업은 덮어쓰지 않는다. 과거 백업 복구는 없는 필드를 현행 값으로 유지한다.

전체 행 원본은 `.backup-prod/release-20261012/full-rows-release-before.json`에 보존한다. 해당 백업과 환경 파일은 Git에서 제외된다. 로컬 운영 DB 자격 증명은 기존 펫지기 전용 파일에서 프로세스에만 전달하며 출력·문서·커밋에 포함하지 않는다.
