2026-10-10 사용자 요청으로 Codex 내장 `image_gen`을 사용해 생성한 홈 전용 AI 자산이다. Gemini 스크립트나 외부 API 키는 사용하지 않았다. 실제 병원·수의사·이용자·보호자의 촬영 사진이 아니며 실제 진료·추천·후기의 증거로 설명하지 않는다.

## 저장과 재현

- 웹용 파일: `public/images/home/*.webp`, quality 82.
- 원본 PNG: `C:/Users/dlatj/.codex/generated_images/01a1253f-9ab2-7242-b1ae-8d0018c88c4b/` (저장소 밖, 원본 유지).
- 전체 생성 프롬프트와 원본 경로: `scripts/home-assets/builtin-manifest.json`.
- 변환: `python scripts/home-assets/prepare.py scripts/home-assets/builtin-manifest.json` (Pillow 필요, 기존 파일 덮어쓰기 거부).
- 중앙 크롭 후 명세 크기로 리샘플링한다. 생성 원본보다 큰 출력은 보간 확대이며 원본 디테일이 추가되는 것은 아니다.
- 용도: 펫지기 홈페이지의 설명용 비주얼. 인물·브랜드·사진 레퍼런스 없이 생성했다. 별도 스톡 라이선스는 사용하지 않았다. 서비스 약관의 별도 검토는 수행하지 않았다.
- 임시 플레이스홀더가 아닌 구현용 생성 자산이다. 사용자 최종 디자인 승인을 뜻하지 않는다.

## 범위

이번 작업은 이미지 준비다. 홈페이지 컴포넌트 연결·반응형 렌더링·브라우저 검증·배포는 수행하지 않았다. 기존 승인 시안 `docs/design/home-approved.png`는 미제공 상태이며 새로 만들어 승인된 파일처럼 저장하지 않는다.
